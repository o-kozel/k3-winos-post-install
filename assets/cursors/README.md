# Архів курсорів

Сюди кладеться zip-архів [macOS Cursors Megapack](https://github.com/antiden/macOS-cursors-for-Windows)
(релізний `macOS-cursors-for-Windows-0.5.zip`). Задача `96-Cursors` бере перший `*.zip` із цієї теки.

Архів **навмисно не входить до репозиторію** (`.gitignore`): це чужі курсори, похідні від Apple; їхні умови - у
`LICENSE.md` усередині архіву. Без архіву задача має статус `SKIPPED` і нічого не змінює.

Який варіант ставити (покоління, тінь, розмір) - у `data\cursors.psd1`.
